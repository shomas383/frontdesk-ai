# こもれび整体院 — RAGデモ用データセット

架空の整体院「こもれび整体院」の資料と、AI受付ボットの評価用テスト質問50問です。
店名・住所・電話番号・人物はすべて架空です。実在の院の文章は使っていません。

## 構成

```
docs/
  01_menu_prices.md          料金・メニュー（初回限定、回数券、学生割引、支払い方法）
  02_hours.md                営業時間・定休日
  03_access.md               アクセス・駐車場
  04_first_visit.md          初めての方へ（院長あいさつ、施術の流れ、服装）
  05_booking_cancellation.md 予約方法・キャンセル・遅刻
  06_faq.md                  よくある質問
  07_news.md                 お知らせ（臨時休業、年末年始、料金改定、古い夏季休業）
eval/
  questions.jsonl            テスト質問50問（正解・期待される動作・出典付き）
```

## わざと入れた「つまずきポイント」

| ポイント | どこ | 確かめたいこと |
|---|---|---|
| 旧料金と新料金が併存 | 07（改定前の料金表） | 現在の料金を答えるか |
| 年末年始の特別営業 | 07 vs 02 | 特例が通常の営業時間より優先されるか |
| 古いお知らせ（2025年夏季休業） | 07 | 古い情報を現在のこととして扱わないか |
| 関係のない長い文章 | 04（院長あいさつ） | 検索のノイズに惑わされないか |
| 同じ情報が別の書き方で2か所 | 01と06（支払い・保険） | 言い回しの違いに対応できるか |
| 書いていないこと | エレベーター、ギフト券など | 推測せずスタッフにつなぐか |
| 症状の相談 | — | 医学的判断や「治る」表現をしないか |

## 質問の内訳（questions.jsonl）

| category | 件数 | expected_behavior |
|---|---|---|
| direct（資料にそのまま書いてある） | 20 | answer |
| paraphrase（言い回しが資料と違う） | 10 | answer |
| multi_doc（複数の情報を組み合わせる・特例） | 5 | answer |
| out_of_scope（資料にない） | 8 | handoff |
| symptom_refuse（症状・医学的判断） | 7 | refuse_redirect |

各行のフィールド：`id`, `category`, `question`, `expected_behavior`, `expected_answer`, `sources`（正解の根拠となる資料）、一部に `trap`（よくある間違い）。

## 使い方のヒント

- `sources` を使って検索精度（recall@k）を測れます。out_of_scope と症状系は `sources` が空か、参考程度です。
- `expected_behavior` を自動判定できるようにしておくと、CIで回答・引き継ぎ・お断りの正しさを測れます。
- 次の段階として、01をPDFの表に、03を画像PDFに変換すると、実際の店舗資料に近い「汚さ」を再現できます。
