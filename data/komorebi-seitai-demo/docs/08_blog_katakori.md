# ブログ：デスクワークの肩こり、放っておいていませんか？

2025年11月10日　こもれび整体院 院長ブログ

## 寒くなると増える肩こりのご相談

最近ぐっと寒くなってきましたね。この時期になると、「肩が重い」「首が回りにくい」というご相談がとても増えます。私自身も会社員時代はデスクワーク中心で、夕方になると肩がガチガチになっていたので、そのつらさはよくわかります。
寒いと体が縮こまり、無意識に肩に力が入りがちです。さらにパソコンやスマートフォンを長時間見ていると、頭が前に出た姿勢が続きます。

## 自宅でできる簡単なセルフケア

- 1時間に1回は立ち上がって、肩を大きく回しましょう（前回し・後ろ回し各10回）。
- 湯船にゆっくりつかって体を温めるのもおすすめです。
- 画面の高さを目線に近づけるだけでも、首への負担は変わります。

※セルフケアで痛みが強くなる場合は、無理をせず中止してください。
